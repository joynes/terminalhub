TerminalHub Privacy Policy

Last updated: June 26, 2026

TerminalHub is an Android SSH project workspace for starting, organizing, and resuming terminal projects on servers and workstations that you choose.

Information handled by the app

TerminalHub can store app data on your device, including:

  • SSH server names, hostnames, ports, usernames, and project paths.
  • SSH authentication data such as passwords, private keys, and key passphrases.
  • Terminal sessions, command input history, session logs, app logs, and crash or diagnostic logs.
  • Files that you explicitly select for upload to a remote server.
  • Optional biometric lock settings used to protect access to the app on your device.

How information is used

The app uses this information to provide SSH connections, restore sessions, upload files, diagnose connection issues, and protect access to the app.

TerminalHub does not use advertising, does not sell personal data, and does not use your data for cross-app tracking.

Data sharing

TerminalHub does not send your app data to the developer's servers.

When you connect to a server or transfer files, the data needed for that action is sent to the server you configured. That server is controlled by you or by the service provider you choose.

If Android backup is enabled on your device, Android may back up app data according to your device and Google account settings.

Security

Sensitive SSH data is stored using Android device security features where available. You are responsible for the servers you connect to, the credentials you enter, and any files or commands you send through those connections.

Children

TerminalHub is intended for users who manage SSH servers or developer workstations. It is not directed to children.
